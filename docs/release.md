## First admin

1. Register the operator through the public form and verify the email.
2. From a trusted database connection, run `UPDATE users SET role = 'admin' WHERE email = 'operator@example.com' AND email_verified_at IS NOT NULL;`
3. Sign in and open `/admin`. The overview must load.
4. To remove access, set `role` back to `user`. The next admin request returns 404.

Do not add an admin email environment variable or a public promotion route.

## Before real users pay

Leave `PAYMENT_*`, `EMAIL_*`, `AI_*`, and `AI_TRANSCRIPTION_*` unset until each provider has been exercised against its sandbox or production endpoint. Unset payment keeps checkout unavailable. Unset email does not verify an account. Unset transcription returns `SPEECH_UNAVAILABLE`. Unset AI returns `AI_UNAVAILABLE` outside development. `fake` providers and the development runner token are rejected when `NODE_ENV=production`.
