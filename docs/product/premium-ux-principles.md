# Premium UX principles

Lindel is a premium digital academy for serious developers. The public product name remains Müəllim. The visual system is specified in `docs/brand/design-system.md`.

The feeling to earn is calm, then focus, then curiosity, then progress, then mastery. The screen should be understandable in a few seconds. Spectacle is not a goal.

## What the product is

A place to continue a lesson, answer a teacher, practice, and see what is solid and what needs another look.

The dashboard is a personal learning home. The lesson is a digital classroom. The teacher is a teacher. The skill map is a competency list. Revision is a calm reminder, not an alert.

## What the product is not

It is not a crypto dashboard, a hacker IDE, a game, an AI landing page, a generic admin console, or a dark SaaS template. It does not add streaks, points, badges, or leaderboards through visual design.

## How the interface earns trust

- One accent, academic indigo, used for the action and the selected mark.
- Warm paper and warm ink in both themes. Dark is primary. Light is a designed textbook surface.
- Hierarchy comes from type size, weight 600 on headings, and whitespace.
- A card is a meaningful object, such as the current lesson. Paragraphs, statistics, and concept rows are not cards.
- Radius stays at 4, 6, or 8. Elevation is a border or a one-step surface change.
- Motion is 150–180ms, and it disappears under `prefers-reduced-motion`.
- Color never carries state alone. Azerbaijani sentences stay the authority.
- One primary button per view. Targets are at least 44px. Contrast meets WCAG 2.2 AA.
- Empty and error states say what to do next. Technical failures stay in logs.

## What this redesign does not change

Mastery, curriculum, prerequisites, assessment, the personalized path, adaptive learning, the revision schedule, the AI provider, authentication, and the database stay as they are. The client does not invent minutes, scores, or due dates the server did not send.
