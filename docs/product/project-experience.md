# Project experience

The student project workspace is the presentation of the existing project domain.

The server decides whether a project is visible, which milestone is current, which files can be edited, and whether a submission passes. The page shows that decision in sentences: what the student is building, which skills the project already names, what the current milestone asks for, and how the check came back.

The mentor block uses the existing explain, hint, and review actions. Those replies are advice. They do not complete a milestone.

A finished project shows the portfolio record when the server has one, and points at the achievements page for the derived learning milestone. There is no separate award on the project page.

See `docs/product/taskflow.md` for the TaskFlow workspace in particular.
